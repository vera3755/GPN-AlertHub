# GPN AlertHub

Прототип единой платформы управления событиями и уведомлениями для систем мониторинга Zabbix, SolarWinds и Prometheus.

## Запуск

### Требования

- Windows 10/11
- Python 3

Дополнительные библиотеки устанавливать не требуется.

### Вариант 1 — быстрый запуск

1. Клонировать или скачать репозиторий.
2. Открыть папку проекта.
3. Запустить файл:

   `run.bat`

4. После запуска автоматически откроется браузер.

Если браузер не открылся автоматически, перейти по адресу:

`http://127.0.0.1:8767`

### Вариант 2 — запуск вручную

В командной строке из папки проекта выполнить:

`python server.py`

или:

`py server.py`

После появления сообщения:

`GPN AlertHub started`

открыть:

`http://127.0.0.1:8767`

## Как проверить работу

Для быстрой демонстрации:

1. Открыть раздел **«Генератор событий»**.
2. Нажать **«P0: SW-17 → DB-17 → БУ-17»**.
3. Перейти в **«AI / Инциденты»**.

Система должна показать:

- 3 входящих события;
- 1 объединённый инцидент;
- вероятную первопричину `SW-17`;
- нормализацию и корреляцию событий.

4. Открыть **«TrueConf (эмулятор)»** и проверить доставку уведомлений.
5. Нажать **«Принять в работу»**.
6. В разделе **«Мои подписки»** можно изменить подписку пользователя и повторить генерацию события.
7. В разделе **«Дашборд»** отображаются показатели обработки событий.

## Примечание

В демонстрационной версии:

- события Zabbix / SolarWinds / Prometheus генерируются встроенным генератором;
- LDAP/AD и CMDB эмулируются;
- вместо реального API TrueConf используется Mock-провайдер.

Это позволяет полностью продемонстрировать end-to-end сценарий локально и без доступа к корпоративному контуру.
